# مكتبة سيف العشيرة

فهرس مكتبة منزلية عربية (RTL)، مبنيٌّ بـ React + TypeScript + Vite ومتّصلٌ بـ [Convex](https://convex.dev)،
ويُنشر ثابتًا على GitHub Pages.

هو أداة فهرسةٍ لصاحبٍ واحد ومعه زوّار:

- **صاحب المكتبة** يدخل بحسابه فيُدخل كل شيء: الكتب، والمؤلِّفين، والأرفف، والتصانيف، والإعارات،
  وحالة القراءة، والتقييم، والملاحظات، والنُّبَذ، والفوائد والمقتطفات، وصور الأغلفة والكعوب.
- **الزوار** يتصفّحون قراءةً فقط، وصاحبُ المكتبة يتحكّم بدقّةٍ فيما يرونه: حقلًا حقلًا، وتصنيفًا
  تصنيفًا، وكتابًا بعينه، وميزةً ميزة.

## الصفحات

صفحة الهبوط · تصفّح المكتبة (شبكة / جدول / **أرفف**) · صفحة الكتاب · المؤلِّفون · صفحة المؤلِّف ·
إضافة كتاب · الإحصائيات — ومعها ثلاث طبقات: البحث، والدخول، والإعدادات.

**عرض الأرفف** هو وجه هذا الفهرس: كل مجلَّدٍ ماديّ يُرسَم كعبًا قائمًا على رفٍّ خشبي، وارتفاعه
يتبع عدد صفحاته، ولونه لون تصنيفه. وإن رفع صاحبُ المكتبة صورةَ كعبٍ لكل مجلَّد وفعَّل عرضها،
صار الرفّ على الشاشة صورةً من رفّ البيت.

## ١. إعداد قاعدة البيانات

```bash
npm install
npx convex dev            # ينشئ النشر ويولّد convex/_generated ويدفع المخطّط
npx convex run seed:run   # الزرع الأوّل: رفّ وتصنيفات وإعدادات وشريحة الهبوط
```

المخطّط في [`convex/schema.ts`](./convex/schema.ts) وهو مصدر الحقيقة. ويبقى
[`supabase/schema.sql`](./supabase/schema.sql) في المستودع مرجعًا تاريخيًّا للنموذج
لا غير — لم يعد يُنفَّذ.

الجداول:

| الجدول | لماذا |
|---|---|
| `library_owner` | صاحب المكتبة، صفٌّ واحدٌ لا غير |
| `authors` | المؤلِّفون: الاسم والنسب والمولد والوفاة والتقويم والترجمة |
| `books` | الكتاب بكامل بيانات فهرسته |
| `book_works` | صلة الكتاب بغيره: شرحٌ أو حاشيةٌ أو اختصار… |
| `perks` | الفوائد والمقتطفات المستخرَجة |
| `loans` | سجل الإعارة |
| `shelves` · `categories` | الأرفف والتصانيف، يحرّرهما صاحب المكتبة |
| `library_settings` | المظهر والخط وصفحة الهبوط وقواعد الخصوصية |
| `landing_slides` | شرائح صفحة الهبوط: صورةٌ واقتباسٌ وقائله |

## ٢. إنشاء حساب صاحب المكتبة

اضبط بريد المالك على النشر أوّلًا — لا يُقبل سواه في أي مسار مصادقة:

```bash
npx convex env set OWNER_EMAIL you@example.com
```

ثم شغّل الموقع واضغط **«دخول صاحب المكتبة»**، فأوّل حسابٍ يُنشأ يَحجز الملكية
مرةً واحدة. لا تسجيل عام ولا تأكيد بريد، ولا حاجة إلى إغلاق التسجيل يدويًّا:
`profile()` في [`convex/auth.ts`](./convex/auth.ts) يرفض أي بريدٍ غير المضبوط.

## ٣. متغيّرات البيئة

```
VITE_CONVEX_URL=https://xxxxxxxxxxxx.convex.cloud
```

- محليًّا: يكتبه `npx convex dev` في `.env.local` وحده. (و`.env.example` للمرجع.)
- للنشر: أنشئ **Deploy Key** من لوحة Convex ← Settings، وضعه في
  **Settings ← Secrets and variables ← Actions** باسم `CONVEX_DEPLOY_KEY`.
  يتكفّل `npx convex deploy` بضبط `VITE_CONVEX_URL` وقت البناء.
- واضبط `OWNER_EMAIL` على نشر الإنتاج أيضًا: `npx convex env set --prod OWNER_EMAIL …`

## ٤. التشغيل

```bash
npm install
npm run dev       # خادم التطوير
npm run build     # بناء للنشر
npm run preview -- --base /Sword-of-the-Clan/   # معاينة ما بُني
```

> عند المعاينة لا بدّ من `--base` لأن مسار النشر على GitHub Pages فرعيّ، وإلا لم تُحمَّل الملفات.

## ٥. نموذج الخصوصية

هذا أهمّ ما في المشروع، ومكانه تبويب **«الزوار»** في الإعدادات.

**القاعدة: ما يُخفى لا يصل إلى الزائر أصلًا، لا أن يُخفى في متصفحه.**

لا وصول مباشر إلى الجداول أصلًا: كل قراءةٍ تمرّ بدالة Convex تعرف هويّة طالبها من
الخادم لا من دعوى العميل. فإن لم يكن صاحب المكتبة مرّت البيانات بـ
[`convex/privacy.ts`](./convex/privacy.ts) الذي يحذف الصفوف المخفيّة ويُفرِّغ الحقول
المخفيّة **قبل أن تخرج الاستجابة**. ولو فُتحت أدوات المطوّر أو نُوديت الدالة مباشرةً
لم يظهر شيء.

ما يتحكّم فيه صاحب المكتبة:

- **عشرة مفاتيح** لما يراه الزوار: حالة القراءة، والتقييمات، والملاحظات الشخصية، ونبذة الكتاب،
  والفوائد، وسجل الإعارة، وقيمة الكتاب، وصفحة الإحصائيات، وصفحات المؤلِّفين، والبحث المتقدِّم.
  (الملاحظات والإعارة والقيمة مخفيّةٌ افتراضيًّا.)
- **٢٣ حقلًا** من بيانات الكتاب، كلٌّ يُضاء أو يُطفأ وحده.
- **تصنيفات** بأكملها: إخفاء تصنيفٍ يُخفي كل كتبه من كل مكان — الشبكة والجدول والأرفف والبحث
  والعدّادات والإحصائيات وصفحات المؤلِّفين.
- **كتبٌ بعينها**.

وقائمة المخفيّ نفسها لا تُنشر للزائر، فلا يعرف حتى أنّ هناك ما هو مخفيّ.

كذلك **«وضع التصفُّح فقط»**: يرى فيه صاحبُ المكتبة بياناته كاملةً (فالخصوصية شأن الزوار)،
لكن تختفي أدوات التعديل ليقرأ كما يقرأ الناس.

## ٦. التقاويم والتواريخ

- كل حقل تاريخ يقبل: `هـ` · `م` · `ق.هـ` · `ق.م`.
- **ما قبل الهجرة والميلاد يُكتب موجبًا**: `١٢٢ ق.هـ` و`٣٨٧٢ ق.م`، ولا يُخزَّن رقمٌ سالب أبدًا.
  والسالب لا يظهر إلا في الحساب الداخلي لتوحيد التقاويم عند الترتيب.
- تاريخ الاقتناء له منتقٍ هجريٌّ مبنيٌّ على تقويم **أم القرى** عبر `Intl`، لا على تقريبٍ حسابي.
- ترتيب المكتبة الافتراضي بأقدمية وفاة المؤلِّف، والأقدمُ أوّلًا، ومن لا تاريخ له يُؤخَّر.

## ٧. البحث

البحث السريع يشمل الحقول كلها ويتغاضى عن التشكيل والتطويل والهمزات والتاء المربوطة،
فـ «اسلام» تجد «إسلام». والبحث المتقدِّم يفتح أربع خصائص للمطابقة (حساسية الأحرف، ومراعاة
الهمزات، والتطابق التام، والكلمات غير المتتالية) واختيار الحقول التي يُبحث فيها.

## ٨. الصور

الأغلفة والكعوب وصور صفحة الهبوط تُرفَع إلى مخزن Convex بالنقر أو الإفلات.
القراءة للجميع، والرفع لصاحب المكتبة وحده. الكتاب ذو الثلاثة عشر مجلَّدًا له ثلاثة عشر موضع
كعبٍ، ويُرسم بثلاثة عشر كعبًا على الرف.

## ٩. الخطوط والمظهر

ثلاثة مظاهر (`دافئ فاتح` · `ورقي` · `جلدي داكن`) وثلاث اقترانات خطوط، وحجم واجهة من ٨٥٪ إلى ١٢٥٪.
أميري و«مرزي» والقاهرة و«تجوّل» تُحمَّل من Google Fonts.

خط **«كتاب»** ملفٌّ محلّي مرخَّص لا يُشحن هنا؛ ضع `Kitab-Regular.ttf` في `public/fonts/` ليعمل،
وإن لم يوجد تراجعت الواجهة إلى أميري دون أن ينكسر شيء.

الزائر له أن يبدّل المظهر لنفسه (يُحفظ في متصفحه)، ولا يمسّ ذلك إعدادات المكتبة.

## ١٠. النشر

`.github/workflows/deploy.yml` يبني وينشر على GitHub Pages عند كل دفعٍ إلى `main`.
والتوجيه بعنوان التجزئة (`#/book/…`) حتى تعمل الروابط المباشرة على GitHub Pages بلا إعدادات خادم.

## بنية المشروع

```
src/
  lib/        الأنواع والثوابت · المظهر · التقويم الهجري · البحث · طبقة البيانات · الموجّه
  components/ الترويسة · الطبقات الثلاث · القطع المشتركة · رفع الصور · منتقي التاريخ
  views/      الهبوط · التصفّح · صفحة الكتاب · المؤلِّفون · إضافة كتاب · الإحصائيات
convex/
  schema.ts   الجداول والفهارس · privacy.ts الخصوصية · auth.ts المصادقة
  library.ts  القراءة · books.ts و catalog.ts الكتابة · images.ts الصور
supabase/
  schema.sql  مرجع تاريخي للنموذج قبل الهجرة — لا يُنفَّذ
public/assets/ الشعار وصورة صفحة الهبوط
```
