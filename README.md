# مكتبة سيف العشيرة

موقع ثابت (Static Site) لفهرسة مكتبة منزلية شخصية، بواجهة عربية RTL مُصمَّمة بالكامل، مبني بـ React + TypeScript + Vite ومتصل بـ [Supabase](https://supabase.com) عبر `supabase-js`.

## المزايا

- **واجهة رئيسية** بشعار المكتبة، غلاف رفوف كتب مرسوم، واقتباس يومي عن الكتب والقراءة، وشريط إحصاءات سريع (عدد الكتب، قيد القراءة، الاستعارات القائمة، الزيارات).
- **تصفّح بلا حساب**: عرض فهرس الكتب، سجلّ الزيارات، وسجلّ الاستعارات متاح للجميع دون تسجيل دخول.
- **التعديل يتطلّب حسابًا**: إضافة/تعديل/حذف كتاب، تسجيل زيارة أو استعارة، كل ذلك يفتح نافذة تسجيل دخول عند الحاجة فقط — لا تسجيل عام ولا إنشاء حساب من الواجهة.
- **تصفّح الكتب**: شبكة بطاقات بأغلفة (صورة حقيقية أو غلاف بديل مولَّد تلقائيًا بلون ثابت لكل كتاب)، بحث وتصفية حسب التصنيف وحالة القراءة.
- **سجلّ الزيارات وسجلّ الاستعارات**: جداول قابلة للفرز مع نماذج إضافة وإجراء "تسجيل الإرجاع" للاستعارات.
- **إعدادات المظهر والخط**: تبديل بين المظهر الفاتح/الداكن/التلقائي (حسب نظام الجهاز)، واختيار أحد أربعة خطوط عربية (Tajawal، Cairo، Amiri، Almarai) وحجم الخط، محفوظة في متصفح الزائر فقط.
- حماية البيانات عبر Row Level Security: القراءة عامة، لكن الكتابة مقصورة على مالك المكتبة المصادَق عليه (`auth.uid() = user_id`).
- نشر تلقائي على GitHub Pages عبر GitHub Actions عند كل push إلى `main`.

## 1. إعداد قاعدة بيانات Supabase

1. افتح مشروعك في Supabase → **SQL Editor**.
2. الصق محتوى الملف [`supabase/schema.sql`](./supabase/schema.sql) ونفّذه. هذا ينشئ جداول `books` و`visits` و`borrows` ويفعّل RLS بحيث:
   - **القراءة (select)** متاحة للجميع بمن فيهم الزوّار غير المسجَّلين (`anon`) — لأن التصفّح لا يحتاج حسابًا.
   - **الكتابة (insert/update/delete)** مقصورة على صاحب الصف المصادَق عليه (`auth.uid() = user_id`) فقط، أي مالك المكتبة.
3. من **Authentication → Users**، أنشئ حسابك الشخصي (بريدك وكلمة مرور) يدويًا — هذا الموقع مخصص لمالك واحد فقط ولا يحتوي على صفحة تسجيل عام.

> ملاحظة أمنية: بما أن القراءة أصبحت عامة، لا تضع في حقول الكتب/الزيارات/الاستعارات أي معلومات لا تريد أن تكون مرئية لأي زائر للموقع.

## 2. متغيرات البيئة (لا تُكتب المفاتيح داخل الكود)

المشروع يقرأ إعدادات الاتصال بـ Supabase من متغيرَي بيئة يستخدمهما Vite عند البناء:

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxxxxxxxxxxxxxxxxxxxxxxx
```

- للتطوير المحلي: انسخ `.env.example` إلى `.env` وضع فيه القيم الخاصة بمشروعك (ملف `.env` مُستثنى من Git عبر `.gitignore` ولن يُرفع أبدًا).
- هذه القيم هي رابط المشروع و"Publishable/Anon key" العام المخصص للاستخدام من جهة العميل — الحماية الفعلية للكتابة تأتي من سياسات RLS في قاعدة البيانات، وليس من سرّية هذا المفتاح.

## 3. تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`). يمكنك تصفّح الموقع مباشرة بلا حساب؛ لتسجيل الدخول (لإجراء أي تعديل) اضغط زر "إضافة كتاب" أو أي إجراء تعديل، وستظهر نافذة الدخول تلقائيًا.

## 4. النشر على GitHub Pages

النشر يتم تلقائيًا عبر سير عمل GitHub Actions الموجود في [`/.github/workflows/deploy.yml`](./.github/workflows/deploy.yml) عند كل push إلى فرع `main`. لتفعيله:

1. في إعدادات المستودع على GitHub: **Settings → Pages → Build and deployment → Source**، اختر **GitHub Actions**.
2. في **Settings → Secrets and variables → Actions → New repository secret** أضف السرَّين التاليين (بنفس الأسماء):
   - `SUPABASE_URL` = رابط مشروع Supabase
   - `SUPABASE_ANON_KEY` = مفتاح Publishable/Anon
3. ادفع (push) إلى فرع `main` — سيقوم سير العمل ببناء الموقع (مع حقن القيمتين أعلاه كمتغيرَي بيئة `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` أثناء البناء فقط) ونشره على GitHub Pages.

> ملاحظة: اسم المستودع مضبوط في `vite.config.ts` (`base: '/Sword-of-the-Clan/'`) ليطابق مسار GitHub Pages الافتراضي `https://<username>.github.io/Sword-of-the-Clan/`. إن غيّرت اسم المستودع، حدّث هذا المسار أيضًا.

## بنية المشروع

```
src/
  lib/
    supabaseClient.ts     # إنشاء عميل Supabase من متغيرات البيئة
    types.ts              # أنواع TypeScript لجداول books/visits/borrows
    AuthContext.tsx        # حالة الجلسة + requireAuth() لفتح نافذة الدخول عند التعديل فقط
    settings.tsx            # حالة المظهر/الخط/حجم الخط المحفوظة محليًا
    useHashView.ts          # توجيه بسيط بين الصفحات عبر hash الرابط (بلا مكتبات خارجية)
    quotes.ts               # اقتباسات عربية عن الكتب والقراءة (اقتباس اليوم)
    coverPlaceholder.ts     # ألوان أغلفة بديلة تلقائية للكتب بلا صورة غلاف
  components/
    Logo.tsx               # شعار المكتبة (سيف + كتاب)
    AppHeader.tsx           # الترويسة: الشعار، التنقّل، زر الإعدادات، حالة الدخول
    SettingsPanel.tsx       # درج إعدادات المظهر والخط
    LoginModal.tsx          # نافذة تسجيل الدخول (تُفتح تلقائيًا عند أي محاولة تعديل)
    BookForm.tsx / VisitForm.tsx / BorrowForm.tsx   # نماذج الإضافة/التعديل
    BookCover.tsx           # عرض غلاف الكتاب أو غلاف بديل مولَّد
  pages/
    Landing.tsx             # الصفحة الرئيسية: الغلاف، الاقتباس، الإحصاءات، بطاقات التنقّل
    BooksBrowse.tsx         # تصفّح الكتب: بحث/تصفية/شبكة بطاقات + CRUD مقيَّد بحساب
    VisitsLog.tsx           # سجلّ الزيارات
    BorrowsLog.tsx          # سجلّ الاستعارات
supabase/
  schema.sql                # جداول books/visits/borrows + سياسات RLS (قراءة عامة، كتابة للمالك)
.github/workflows/
  deploy.yml                # بناء ونشر تلقائي على GitHub Pages
```
